{% docs gross_revenue %}
Gross revenue is the total amount successfully collected from customers
before payment processing fees are deducted.

It is represented by the total successful payment amount.
{% enddocs %}


{% docs net_revenue %}
Net revenue is the amount retained after payment processing fees.

Net Revenue = Successful Payment Amount - Successful Payment Fee
{% enddocs %}


{% docs trip_duration_minutes %}
Trip duration is the elapsed time between trip pickup and drop-off,
expressed in minutes.

A positive trip duration is required for a valid trip.
{% enddocs %}


{% docs corporate_trip_flag %}
Indicates whether a trip is associated with a corporate or business rider.

TRUE represents a corporate trip and FALSE represents a personal trip.
{% enddocs %}


{% docs driver_lifetime_trips %}
The cumulative number of completed trips attributed to a driver.

This metric is used to monitor driver activity and driver engagement.
{% enddocs %}


{% docs rider_lifetime_value %}
The cumulative net revenue generated by a rider from completed trips.

It represents the economic value generated by the rider after
payment processing fees.
{% enddocs %}


{% docs payment_failure_rate %}
Payment failure rate is the proportion of payment attempts that fail.

Payment Failure Rate = Failed Payment Attempts / Total Payment Attempts
{% enddocs %}


{% docs multiple_payment_attempts %}
Indicates whether more than one payment attempt was recorded for a trip.

Multiple attempts may indicate payment retries or payment processing issues.
{% enddocs %}


{% docs duplicate_successful_payment %}
Indicates that multiple successful payment records were associated with
the same trip.

This is treated as a potential duplicate charging or payment integrity issue.
{% enddocs %}


{% docs failed_payment_on_completed_trip %}
Indicates that a completed trip does not have a successful payment.

This is treated as a revenue and payment integrity exception because
completed trips are expected to have a successful payment.
{% enddocs %}


{% docs extreme_surge_flag %}
Indicates whether the trip had a surge multiplier greater than 10.

This identifies unusually high surge pricing for operational and
fraud monitoring.
{% enddocs %}
